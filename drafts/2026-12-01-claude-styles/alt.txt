1. شريحة فاتحة برسم ورقتين وختم «بصوتي أنا»، واقتباس: «مبيّن ذكاء اصطناعي.. مش أنا» قلتها لـClaude عن مسودة كتبها لي. والعنوان: علّم Claude أسلوبك من كتاباتك أنت. وشارة Styles · Claude وزر «اسحب».
2. شريحة بيضاء بكلمة Styles كبيرة مفرغة، وعنوان «بمعنى أبسط»: أسلوب تختاره فيكتب Claude بطريقته، وأربعة أساليب جاهزة: Normal الرد المعتاد، Concise أقصر وأكثر مباشرة، Formal واضح ومصقول، Explanatory تعليمي. والأهم: أسلوبك أنت من نماذج تكتبها بيدك.
3. شريحة زرقاء داكنة بعنوان «خمس نقرات.. وخلاص»: Search and tools ثم Use style، Create & edit styles، Create custom style، Add Writing Example وارفع كتاباتك أو الصقها، Create style.
4. شريحة زرقاء بعنوان «اختر نماذج تشبهك فعلًا»: ارفع منشورات أو رسائل كتبتها بنفسك بملفات PDF أو Word أو نص، ولا ترفع نصًا كتبته أداة ثم عدّلته قليلًا. وما عندك نماذج؟ اختر Describe style instead.
5. شريحة بيضاء بعنوان «بس انتبهوا..» وأربع بطاقات: تغيّره متى شئت، عاينه وعدّله من Edit Style، لكل مهمة أسلوب، والقرار لك. وفي الأسفل: جرّبوها وقولوا لي.
